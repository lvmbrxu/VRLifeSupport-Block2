# Virtual Life Support

A hand-tracked VR CPR training prototype built in Unity for Meta Quest. The project puts the player inside a complete emergency scenario and gives live feedback on compression rhythm and depth.

## What I worked on

I focused on the CPR interaction, the feedback monitor and the flag-based system that controls scenario progression. I also helped with player guidance, environment work and team planning.

The main technical work included:

- validating both hands before accepting a compression;
- turning hand movement into continuous chest compression;
- calculating and displaying BPM and compression depth;
- driving an ECG-style waveform from compression events;
- unlocking scenario actions only when their prerequisites are complete.

## Project context

- **Engine:** Unity
- **Platform:** Meta Quest
- **Team:** 5 students
- **Duration:** 8 weeks
- **My focus:** C#, VR interaction and scenario systems

The prototype received 11/12 points and was selected as the strongest of five student prototypes.
